# UI/UX Skill

## When to Use
Design systems, accessible components, responsive layouts.

## Protocol
1. Design tokens (color/spacing/type) before components.
2. WCAG AA contrast minimum; keyboard navigation mandatory.
3. Mobile-first responsive; test at 320px and 1440px.
4. States: loading, empty, error, success — all designed.

## Verification
Keyboard-only walkthrough works; contrast passes AA; layouts hold at breakpoints.
