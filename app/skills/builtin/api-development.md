# API Development Skill

## When to Use
Designing or building REST/GraphQL APIs.

## Protocol
1. Resource-oriented URLs; version from day one.
2. Uniform error shape + correct status codes.
3. Validate at the boundary; reject early with actionable messages.
4. OpenAPI spec kept in sync with implementation.

## Verification
Contract tests pass; spec matches routes; error responses follow the shape.
