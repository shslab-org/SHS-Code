# Documentation Skill

## When to Use
READMEs, API references, architecture docs.

## Protocol
1. Audience first: user docs vs contributor docs vs API reference.
2. Runnable examples — every code block should be copy-pasteable.
3. Document WHY for decisions; WHAT belongs in code.
4. Keep a changelog for user-facing changes.

## Verification
Examples in docs actually run; new user can get started from README alone.
